# 打卡 · Checkin

一款**默认纯本地运行**的多类型打卡 Android 应用，强调自制力工具属性。所有数据默认存储在设备本地，不上传、不同步；**可选联网增强**（设置页开关，用户自行填入高德 API Key 后才发起逆地理编码请求，默认关闭）。支持多种打卡方式自由组合、负打卡（状态反转）规则、连续打卡抵消机制、多日期排期（每周固定几天 / 双休 / 大小周）、随心记（日记式）模式、心情日记（5 档心情 + 可选文字 + 备注栏折线图）、时间打卡（倒计时 / 正计时 / 暂停续时），并可将全部数据导出为 JSON 供 PC 端解析。

> 当前版本：**v1.3.3**（versionCode 82） · 最低系统：Android 7.0+（API 24） · 目标 API 34 · 语言：Kotlin

## 功能特性

- **默认纯本地运行**：默认无网络请求、无云端同步、无后台常驻 Service，数据 100% 留在设备上；设置页可选「联网增强」（见 v1.3.0）。
- **心情日记（v1.3.0）**：创建页双 tab「✅ 普通打卡 | 📔 日记打卡」中的日记模式可选**心情日记**——5 档心情（😄 开心 / 🙂 不错 / 😐 一般 / 😟 低落 / 😖 很差）必选，可附一段文字；日历圆圈 = 当天**最后一次带心情记录**的心情色，无记录无底色；备注栏每条记录显示心情 emoji + 文字，当天 ≥2 条带心情且开关开启时在记录区第一行画**心情折线图**（新自定义 View MoodLineView）；「n 次 / n 天」只计**带心情的记录**（附文字不额外计）；「记录 / 继续记录（N）」按钮；折线图开关在创建页与打卡页 ⋮ 菜单随时可改。
- **创建页双 tab（v1.3.0）**：打卡类型「普通打卡 | 日记打卡」——普通 tab 保留原全部规则内容（移除打卡模式选择区）；日记 tab 为全新简洁页（记录类型随心记 / 心情日记单选 + 方式 + 心情折线图开关），**日记项修改策略固定 FLEX（随时可改，不锁定）**。
- **位置联网增强（v1.3.0）**：设置页「联网增强」总开关（默认关）→「定位增强」→ 高德 API Key 输入框三级联动；开启后打卡时把经纬度逆地理编码为地名（locName）随记录快照保存，显示「📍 地名 + 距离」；**不内置任何 Key**，关闭增强或请求失败时回退显示经纬度，历史记录不受开关影响。
- **多类型打卡**：普通、拍照、文字、位置、步数、时间（倒计时 / 正计时）、扫码、NFC、语音、自动共 10 种打卡方式。
- **自由组合打卡**：每种方式是一个独立布尔开关，可多选组合；打卡时弹出「方式卡片」，逐项完成，全部完成后当天变绿。**组合完成数（v1.2.0）**：多选时可设「完成任意 N 项即完成」（0 = 全部），部分完成当天显示 🟡 部分完成。**环形调节（v1.2.2）**：完成数 1~总数−1 显示数字，总数显示「全部」，+ / − 双向循环不卡边界（总数=3 时：全部→1→2→全部→1…；点 − 反向同理）。
- **随心记模式（v1.2.0）**：日记式记录——只记成功、不记缺卡、不设排期；每天可多次记录，只要有一次记录当天就变绿，按钮为「记录 / 继续记录」，记录天数「有记录 +1、断签不清零」；每日次数固定为不限；拍照 / 文字 / 位置 / 扫码 / 语音可用，普通 / 自动 / NFC / 步数 / 时间打卡置灰，点击弹出带颜文字的「暂不支持」提示。
- **负打卡（状态反转）**：操作 = 破戒失败，无操作 = 默认成功。适合「戒手机」「戒零食」「早睡」等反向自制场景，可叠加于任意方式。
- **连续打卡抵消机制**：累积型（A）/ 阈值型（B）/ 周期型（C）三种模式，自动发放 🛡️ 抵消机会，可补漏签。
- **多日期打卡排期**：创建时可选择「每天 / 每周固定几天 / 双休 / 大小周」；无需打卡的日子以橙色标注、打卡页提示「今日无需打卡」，且**不中断连续打卡天数**。
- **快捷打卡**：首页只专注一个打卡项；在打卡管理页长按卡片即可切换，随时更换首页专注对象。
- **打卡日历**：月历视图展示从创建至今每天的状态（成功 / 失败 / 补签 / 自动 / 无需打卡 / 今天）；自动打卡与手动一致显示绿色、缺卡次日显示红色、无需打卡日显示橙色，今天未打卡只保留主题色描边（不填充）；点击任意过去日期可查看当天打卡详情（时间、文字、图片、语音）。
- **修改策略**：创建时可选「不可修改」或「N 天可改一次」，锁定规则防自己作弊。
- **主题系统**：8 套花卉植物风格主题（樱花、向日葵、薄荷、薰衣草、珊瑚、海洋、玫瑰、多肉）；**仅保留主题 emoji 与打卡按钮 / 今天描边颜色**，不做花哨装饰。
- **数据导出**：一键导出全部打卡项、打卡记录、抵消记录为 JSON 文件，便于 PC 端分析与备份。
- **状态与文件独立**：打卡状态写入数据库即为最终状态，图片/语音文件丢失不影响打卡记录。
- **固定时间段打卡（v1.1.6）**：设定一个时间窗口（如 5:00–8:30 早起场景），仅窗口内可打卡成功；与负打卡互斥（圆形单选），不支持跨天窗口（如 23:00–01:00），开启后不可选择自动打卡；窗口外打卡按钮禁用并提示「未到打卡时间 / 已过打卡时间」；**超过结束时间未打卡当天直接红色缺卡**（v1.1.7 起，无需等到第二天）。
- **时间打卡（v1.2.0）**：原名「倒计时打卡」，现支持两种计时模式——**倒计时**（从设定时长倒数，时间到才能完成）与**正计时**（从 0 开始，超过设定时长后才能完成；达标后若不操作，时间继续向前，最终按点击完成时的实际用时记录）。两种模式均支持**暂停保存 / 恢复**：任意时段「暂停保存」写入进度，下次打卡或杀后台后重进可继续计时；暂停的当天显示 🟡 部分完成，备注栏展示「已走 / 剩余」进度。**v1.2.1 起暂停仅正计时可用**：倒计时打卡弹窗与创建页均不再显示「暂停保存」/「允许暂停保存」（倒计时无法暂停则无意义）；负打卡开启时只保留倒计时（隐藏正计时与暂停选项）。
- **无限次数打卡（v1.1.7）**：每日次数设为「不限」后，打一次立即完成当天状态（正常打卡变绿 / 负打卡破戒变红），按钮不锁定并显示「再打卡（N）」，可继续追加记录，日期下方同步累计 n 次。
- **拖拽排序（v1.1.7）**：打卡管理页长按卡片右侧 ⋮⋮ 手柄上下拖动排序；置顶项固定在顶部不可拖，取消置顶后回到未置顶区最上方；排序持久化保存。
- **打卡页顶栏主题 emoji（v1.1.7）**：从列表进入的打卡操作页顶栏显示主题 emoji + 名称，不再空荡荡。
- **图例优化（v1.1.7）**：图例第一行「○今日未打卡」放首位；彩色圆点改用带颜色的小号色点；两行间距统一加宽。
- **录音按钮统一配色（v1.1.7）**：语音打卡的录音 / 播放按钮统一为青色 #39C5BB + 白字，修复时灰时绿问题。
- **图标栏（v1.3.0）**：随心记「○今日 / ●已记录」（两行）；心情日记「○今日 / 5 档心情色点」+ 第二行「今天没记录 / 记录心情 / 可附文字」；🔥 连续 N 天文字改深灰 #4A4A4A（红色易与缺卡撞色）。
- **无内容记录补提示（v1.2.2 扩展，v1.3.0）**：无计时 / 文字 / 位置 / 媒体时追加「完成普通打卡 / 完成自动打卡 / 完成心情打卡」。
- **App 图标 / 空状态封面（v1.3.0）**：启动器图标与快捷页空状态占位图替换为初音未来 Q 版形象（`cover_miku.jpg`）。

## 打卡方式

| 方式 | 说明 | 备注 |
|---|---|---|
| ✅ 普通打卡 | 点一下即完成 | |
| 📷 拍照打卡 | 拍照或从相册选图，自动压缩为 WebP 缩略图存储 | 相机不可用时自动降级相册，图片保存失败不影响打卡状态 |
| 📝 文字打卡 | 输入文字完成 | 可设最低字数（1–99）、可开启「不可与上次重复」；备注栏直接衔接文字（无「文字：」前缀，v1.3.0）；普通打卡 >120 字折叠 5 行 + 「…展开」，日记全文不折叠 |
| 📍 位置打卡 | GPS 定位判定是否在设定范围内 | 支持负打卡模式（离开设定点才算成功） |
| 👟 步数打卡 | 读取系统计步传感器，达标后确认 | 需身体传感器权限；v1.1.3 起为「开发中」占位 |
| ⏳ 时间打卡 | 倒计时或正计时，达标后可完成；支持暂停保存续时 | 倒计时：时间到才可完成；正计时：超过目标时长后可完成，记录实际用时 |
| 🔳 扫码打卡 | 扫描创建时生成的唯一二维码，或扫码绑定现有二维码 | 需相机权限 |
| 📡 NFC 打卡 | 碰一碰 NFC 标签，比对标签 ID 后自动完成打卡 | 快捷页与打卡操作页均可读标签 |
| 🎤 语音打卡 | 录制语音完成，AAC 压缩存储 | 可设定最大录制时长 |
| ⚡ 自动打卡 | APP 前台触发（冷启动 / 恢复前台）自动完成当天打卡；**每日次数固定为 1（v1.2.2）** | 触发时展示非阻断式提示，不静默 |

> 多选任意 ≥2 个不冲突的方式即成为**组合打卡**：打卡时按方式卡片逐一完成，各自独立记录。**已完成的方式当天持久化显示 ✅ 且不可重复打卡**（退出重进仍保留，随心记除外）；组合打卡每日次数固定为 1；打卡按钮文案按「打卡 → 继续打卡 (n/总数)」递进。**v1.2.0 起可设完成数**：如 5 个打卡项完成任意 3 个即视为当天完成（部分完成显示 🟡）。

## 打卡日期排期（v1.1.3）

创建打卡项时可选择打卡日期排期。**无需打卡的日子**在日历中以**橙色**标注、打卡页提示「今日无需打卡」，且**自动视为完成、不中断连续打卡天数**：

| 模式 | 说明 |
|---|---|
| 每天 | 默认排期，每天都需打卡 |
| 每周固定几天 | 周一~周日 7 个圆形多选，仅选中的日子需打卡（选中绿色高亮） |
| 双休 | 周一~周五需打卡，周六、周日休息 |
| 大小周 | **大周 = 单休**（周六也需打卡，周日休息）；**小周 = 双休**（周六日都休息）；创建时选择当前周是大周还是小周开头，之后按周交替 |

## 核心规则

### 负打卡（状态反转）

| 场景 | 显示状态 |
|---|---|
| 某天**执行了**打卡操作 | 该天显示为「未打卡」（失败） |
| 某天**没有**任何操作 | 该天显示为「已打卡」（成功） |

克制自己不去打卡 = 打卡成功。负打卡可与所有手动方式叠加。

### 随心记模式（v1.2.0）

创建页打卡类型双 tab「✅ 普通打卡 | 📔 日记打卡」（v1.3.0）；日记 tab 内记录类型再单选「📔 随心记 | 😊 心情日记」（点击单选不取消）。随心记 = **日记式记录**，与普通打卡的规则体系完全独立：

| 维度 | 行为 |
|---|---|
| 记录语义 | 只记成功，不记缺卡；当天无操作不产生任何失败/缺卡标记 |
| 每日次数 | 固定为「不限」，不可修改（频率与规则区 +/− 点击弹出提示） |
| 排期 | 不设排期（每周固定几天 / 双休 / 大小周全部禁用，点击弹提示） |
| 连续天数 | 不计算连续天数，改为**记录天数**：有记录 +1，断签不清零 |
| 可记录方式 | 拍照 / 文字 / 位置 / 扫码 / 语音（单选或多选均可，可反复多次记录） |
| 禁用方式 | 普通 / 自动 / NFC / 步数 / 时间打卡：开关**置灰但可点击**，点击弹出带颜文字的「暂不支持」提示 |
| 其他禁用 | 负打卡、固定时间段打卡、打卡日期排期、连续抵消机制（同上，置灰可点 + 颜文字提示） |
| 按钮文案 | 「记录」→ 记录后「继续记录（N）」；当天有记录即绿色，可继续追加 |
| 图标栏 | 第一行「○今日 / ●已记录」，第二行「⏳今天没记录 / ●已记录」（v1.3.0） |

随心记下综合打卡（多方式）的完成判定不生效——每个方式每次记录都是一条独立记录，可一天多次。

### 固定时间段打卡（v1.1.6）

设定一个当天内的时间窗口（如 05:00–08:30），**只有在该时间段内打卡才能成功**，适合早起 / 固定时段做事等场景：

| 时段 | 行为 |
|---|---|
| 窗口内 | 可正常打卡，成功 |
| 窗口外（未到） | 打卡按钮禁用，提示「未到打卡时间（05:00–08:30）」 |
| 窗口外（已过） | 打卡按钮禁用，提示「已过打卡时间（05:00–08:30）」 |

- 与「负打卡」**互斥**（频率与规则区圆形单选，一眼看出单选）。
- 开启后**无法选择自动打卡**；已选自动时也无法开启时间段。
- **不支持跨天窗口**（如 23:00–01:00），创建时校验开始时间须早于结束时间。
- 窗口外无任何操作即当天未打卡；**超过结束时间未打卡当天直接红填充**（v1.1.7 起，无需等次日判定），次日同样保持红色。

### 方式互斥矩阵

- 选了「普通打卡」→ 其余 8 个手动方式开关全部置灰。
- 「自动打卡」与普通 / 拍照 / 文字 / 语音 / 时间（倒计时）/ 扫码 / NFC / **位置 / 步数**互斥（自动触发时无需人工采集素材，v1.2.1 起位置 / 步数也纳入置灰）。
- **负打卡 ↔ 自动打卡互斥（v1.2.1）**：负打卡开启时自动开关置灰、点击弹「温馨提示：负打卡与自动打卡互斥，无法同时开启 ο(=•ω＜=)ρ⌒☆」；自动开启时点负打卡弹同样提示。
- 固定时间段打卡 ↔ 自动打卡互斥（开启时间段后自动开关置灰并弹出「温馨提示」；已选自动时时间段不可选并弹出同样提示，v1.1.7）。

互斥方式开关保持可点击，点击时弹出「温馨提示」说明原因（v1.1.3 起不再静默置灰）。

### 连续打卡抵消机制

创建打卡项时可开启，三选一：

| 模式 | 规则 |
|---|---|
| A 累积型 | 每连续 N 天得 1 次机会，可无限累积，永不过期，断签不清零 |
| B 阈值型 | 每连续达到 N 天补足到 k 次（不叠加），用完后需重新累积 |
| C 周期型 | 每完成一个 N 天周期得 k 次，周期中断签则从第 1 天重新计 |

补签后可手动或自动消耗机会（🛡️×N 显示在卡片上）。

**补签与连续天数（v1.1.3）**：
- 补签（↩）**计入连续天数**：补签把断掉的那天补上，连续打卡不中断，打卡页显示连续天数包含补签日。
- 补签当天自动视为完成：确认补签时，若今天尚未打卡且为需打卡日，会同时记一次成功（补签 = 处理昨日遗漏 + 完成今日）。
- **补签不产生新的抵消机会**：补签只消耗 1 次机会，并把**里程碑周期从补签当天重新起算**（之后需再连续 N 天才发放），避免补签把连续天数顶过里程碑边界后「白拿」新机会；连续天数显示不受影响，仍包含补签日。

### 修改策略

- **LOCKED 不可修改**：创建后规则完全锁定（编辑页所有规则控件置灰，含打卡方式、频率、拍照来源、位置/NFC 读取按钮、参数输入与日期排期），仅名称/图标/主题/备注可改。
- **INTERVAL_N N 天可改一次**：距上次修改不足 N 天时修改入口置灰。
- **FLEX 可随时修改（v1.3.0）**：日记 tab 创建的日记项（随心记 / 心情日记）固定为 FLEX，规则始终可改（详情页展示「可随时修改」），未来扩展功能无需重建。

修改策略本身创建后不可更改（日记项固定 FLEX）。

### 快捷打卡唯一性

- 任何时刻**有且仅有一个**（或没有）快捷打卡项，列表中以 ⭐ 标识。
- 创建第一个打卡项时自动设为快捷打卡；删除快捷打卡项后自动切换为排序最靠前的剩余项；无剩余项时首页显示空状态引导。
- 切换快捷打卡后首页完全刷新（标题、状态栏、日历、记录栏），无残留。

### NFC 打卡（v1.1.3 修复）

- **创建时**：创建页开启 NFC 方式 → 点击「绑定 NFC 标签」，贴近标签后记录标签 ID 并保存；**未绑定标签时禁止保存创建**（v1.1.4 起校验拦截）。
- **打卡时**：在**快捷打卡页**或**从打卡管理进入的打卡操作页**点 NFC 打卡 → 弹出「请贴近标签」对话框 → 手机贴近标签，读到的 ID 与绑定 ID 一致则自动完成打卡并关闭对话框；不一致会提示「NFC 标签不匹配」。
- 前台分发由承载打卡页的 Activity（MainActivity / ItemCheckinActivity）各自注册，标签回调统一经 `NfcHub` 转发给当前激活的打卡页，任何入口都能正常读卡。

## 数据存储与导出

### Room 表

| 表 | 说明 |
|---|---|
| `checkin_item` | 打卡项（名称、类型、configJson、主题、置顶、修改策略、创建时间） |
| `quick_checkin_config` | 全局唯一快捷打卡配置（id 固定为 1） |
| `checkin_record` | 打卡记录（归属日期、时间戳、状态 SUCCESS/FAIL/OFFSET、是否自动、素材路径） |
| `offset_credit` | 抵消机会（模式 A/B/C、发放/使用记录） |
| `auto_checkin_state` | 自动打卡状态（最后自动日期） |

### 文件存储

- 图片：`{内部存储}/checkin_photos/{item_id}/{record_id}.webp`（最长边 ≤480px，质量 60–70%）
- 语音：`{内部存储}/checkin_voices/{item_id}/{record_id}.aac`（16kHz 单声道）
- 打卡状态不依赖文件：文件丢失仅显示占位符，记录保持「已打卡」。

### 导出格式

设置 → 数据导出，生成 `checkin_export_yyyyMMdd_HHmmss.json`，包含 `checkinItems`、`checkinRecords`、`offsetCredits`、`quickCheckinItemId` 等完整数据，JSON 结构便于 PC 端解析与后续导入恢复。
