# 打卡 · Checkin

一款**默认纯本地运行**的多类型打卡 Android 应用，把「每天要坚持的事」做成可自由组合的打卡规则：多种打卡方式任意搭配、按周排期、负打卡（状态反转）、连续打卡抵消、打卡组、习惯天数挑战、时间打卡，以及块流式的随心记与心情日记。所有数据默认只保存在本机；**联网增强**（位置地名解析）默认关闭，只有用户自行填入高德 API Key 并打开开关后才会发起请求。

> 最低系统：Android 7.0（API 24） · 目标 API 34 · 语言：Kotlin

## 功能特性

### 基础能力

- **纯本地运行**：无账号、无云端同步、无后台常驻 Service，数据全部留在设备上。
- **多种打卡方式**：普通、拍照、文字、位置、步数、时间、扫码、NFC、语音、自动，可自由组合。
- **四种创建类型**：自定义打卡、打卡组、习惯打卡、日记打卡（日记内再分随心记 / 心情日记）。
- **打卡日期排期**：每天、每周固定几天、双休、大小周；无需打卡日自动视为完成、不中断连续。
- **负打卡**：操作 = 破戒，无操作 = 成功，适合戒手机 / 戒零食等反向自制场景。
- **连续打卡抵消**：累积型、阈值型、周期型三种发放方式，用 🛡️ 补漏签；负打卡破戒还能被盾牌当场抵消为补卡。
- **快捷打卡**：全局唯一，首页专注一个打卡项，⭐ 标识；删除或暂停时自动递补。
- **打卡日历**：月历展示每天状态，点击过去日期查看当天详情（时间、文字、图片、语音、位置、心情）。
- **修改策略**：创建时可选「不可修改」「N 天可改一次」或「随时可修改」，锁定规则防作弊。
- **主题系统**：全局 6 套莫兰迪主题 + 打卡项 8 套花卉点缀色 + 21 个独立图标。
- **数据导出 / 导入**：全部或部分打卡项导出为 JSON / ZIP，支持从本应用导出的文件一键合并恢复。
- **状态与文件独立**：打卡状态写入数据库即最终状态，图片 / 语音文件丢失不影响记录。

### 数据与隐私

- 默认不联网；仅「联网增强」会在开启后调用高德逆地理编码接口，且 Key 由用户自备，不内置。
- 素材存放在应用内部目录，不申请公共存储权限（仅 API 28 及以下为保存二维码申请旧版存储权限）。
- 导入前自动备份当前数据到应用缓存目录。

## 创建与打卡类型

点打卡管理页右上角「＋」进入类型选择页，有四个入口：

| 类型 | 说明 |
|---|---|
| 自定义打卡 | 按规则打卡，有缺卡与连续天数；方式、次数、负打卡、时间段、抵消、排期全部可配 |
| 打卡组 | 组内多个普通打卡子项，**子项全部完成**后组自动记为成功；组可单独设打卡日期 |
| 习惯打卡 | 设定目标天数（1–999），严格连续，中断清零；达标后可继续超额 |
| 日记打卡 | 日记式记录，不记缺卡；页内再选「随心记」或「心情日记」 |

- **打卡组**：组本身没有打卡方式，卡片显示子项进度环；子项各自可配打卡方式、每日次数、负打卡、时间段、抵消、自动打卡；部分子项完成时组显示黄色「部分完成」。
- **习惯打卡**：显示连续天数与目标进度；支持固定时间段；不提供负打卡；方式可多选组合。
- **日记打卡**：每日次数固定「不限」，不设排期，不支持负打卡 / 固定时间段 / 抵消机制。

## 打卡方式

普通打卡项可选以下方式（互斥规则由界面自动处理）：

| 方式 | 说明 | 备注 |
|---|---|---|
| ✅ 普通打卡 | 点一下即完成 | |
| 📷 拍照打卡 | 拍照或从相册选图，自动压缩为 WebP 存储 | 最多 9 张，可预览删除；相机取消直接返回 |
| 📝 文字打卡 | 输入文字完成 | 可设最低字数、「不可与上次重复」 |
| 📍 位置打卡 | 实时定位判定是否在设定范围内 | 可设多个标准点与半径；支持「离开范围才算成功」 |
| 👟 步数打卡 | 读取系统计步传感器 | 开发中，选择时提示 |
| ⏳ 时间打卡 | 倒计时或正计时，达标后完成 | 倒计时归零自动完成；正计时记录实际用时 |
| 🔳 扫码打卡 | 扫创建时生成的二维码，或绑定现有二维码 | 需相机权限 |
| 📡 NFC 打卡 | 贴近 NFC 标签，比对标签 ID 后完成 | 未绑定标签不能保存 |
| 🎤 语音打卡 | 录制语音完成 | AAC 压缩；可设最长录音时长，最后 5 秒震动提醒 |
| ⚡ 自动打卡 | 打开 App 前台时自动完成当天 | 每日固定 1 次；与负打卡 / 固定时间段互斥 |

日记打卡内置两种记录方式：

| 方式 | 说明 |
|---|---|
| 📔 随心记 | 块流日记：文字 / 图片（三列宫格）/ 语音 / 位置四种块自由穿插，位置固定在末尾 |
| 😊 心情日记 | 5 档心情必选 + 可选文字；日历取当天最后一次心情色，可开关备注栏折线图 |

> 选择任意 ≥2 个不冲突的普通方式即为**组合打卡**：打卡时按方式卡片逐项完成，可设「完成任意 N 项即完成」。组合打卡每日次数固定为 1。

## 打卡日期与时间规则

### 打卡日期排期

| 模式 | 说明 |
|---|---|
| 每天 | 默认排期，每天都需打卡 |
| 每周固定几天 | 周一~周日 7 个圆形多选，仅选中的日子需打卡 |
| 双休 | 周一~周五需打卡，周六、周日休息 |
| 大小周 | 大周 = 单休（周六需打卡），小周 = 双休；创建时选本周开头，之后按周交替 |

无需打卡的日子在日历中以**橙色**标注、提示「今日无需打卡」，并**自动视为完成、不中断连续天数**。

### 固定时间段打卡

- 设定当天内的时间窗口（如 05:00–08:30），仅窗口内可打卡成功；窗口外按钮禁用并提示。
- 超过结束时间仍未打卡，当天直接判定为缺卡（不必等次日）。
- 与负打卡互斥（圆形单选），与自动打卡互斥；不支持跨天窗口。

### 时间分割（凌晨归属前一天）

- 可设定一个凌晨分界点（如 03:00）：该时间之前打卡归属**前一天**，之后归属当天。
- 状态卡会明确显示「（归属 X月X日）」，日历默认选中归属日，连续天数 / 抵消 / 次数判断都按归属日计算。
- 与固定时间段互斥（二选一）。

### 时间打卡

- **倒计时**：从设定时长倒数，归零后**自动完成打卡**，无需再点确认。
- **正计时**：从 0 开始，超过目标时长后可完成，记录实际用时；达标后不操作会继续计时。
- **暂停保存**（仅正计时）：任意时段暂停写入进度，下次打卡或杀后台重进可继续；暂停当天显示黄色。
- **强制模式**：计时期间离开本页（屏幕仍亮）本次计时作废，需重新开始；熄屏解锁后继续计时；与暂停保存互斥。
- 负打卡开启时只保留倒计时（隐藏正计时与暂停选项）。

## 核心规则

### 每日次数与「全部完成」

- 每日次数可设为 1~99 或不限；组合打卡固定 1 次，自动打卡固定 1 次，日记固定不限。
- 单方式且次数 ≥2 时，可开启「需完成全部次数才算打卡成功」：打满 N 次才变绿，未打满显示黄色。
- 次数不限时，打一次即完成当天状态，按钮继续显示「继续打卡（N）」。

### 负打卡（状态反转）

| 场景 | 显示状态 |
|---|---|
| 某天**执行了**打卡操作 | 该天显示为破戒失败（红色） |
| 某天**没有**任何操作 | 该天显示为已打卡（成功） |

- 破戒当天连续天数立即归零（不从昨日回溯）。
- 可与所有手动方式叠加，与自动打卡、固定时间段互斥。
- 持有 🛡️ 时点击破戒，会**消耗 1 个盾牌把本次破戒抵消为补卡**（蓝色、不算破戒次数）；盾牌用完后再次点击才真正记破戒。

### 连续打卡抵消机制

| 模式 | 规则 |
|---|---|
| A 累积型 | 每连续 N 天得 1 次，可累积，断签不清零 |
| B 阈值型 | 每连续达 N 天补足到 k 次（不叠加） |
| C 周期型 | 每完成 N 天周期得 k 次，周期中断签从第 1 天重新计 |

- 补签计入连续天数；补签当天若为空缺会自动补一条成功记录。
- 补签只消耗机会、不产生新机会；里程碑周期从补签当天重新起算。
- 负打卡不自动补历史破戒日，只保留手动补签入口；破戒次数只统计 FAIL 记录。

### 组合打卡

- 多选 ≥2 个不冲突方式。完成数可在 1~总数之间环形调节，达到即完成当天；部分完成显示黄色。
- 已完成的方式当天持久化显示 ✅，退出重进不会重复打；按钮文案按完成数递进（打卡 → 继续打卡 (n/总数)）。

### 修改策略

- **不可修改**：创建后规则锁定，仅名称 / 图标 / 主题可改。
- **N 天可改一次**：距上次修改不足 N 天时规则不可改，界面上有明确提示。
- **随时可修改**：日记项固定使用此策略。

### 快捷打卡

- 任何时刻有且仅有一个（或没有）快捷打卡项，以 ⭐ 标识。
- 创建第一个打卡项时自动设为快捷；删除或暂停后自动递补下一个启用项。
- 快捷打卡与普通项一致，打卡组也可以设为快捷。

### 暂停与排序

- 长按卡片可设为快捷 / 置顶 / 暂停 / 编辑 / 删除；暂停项在列表中灰显、**固定沉到最底部**且不参与拖拽。
- 暂停项无法打卡（所有入口均被拦截），恢复后回到列表原位置。
- 未置顶项可用卡片右侧 ⋮⋮ 手柄拖拽排序；置顶项固定在前且不可拖动。

```
┌─────────────────────────────────────────────┐
│               底部导航栏（3 个主页面）           │
│   ┌──────────┐   ┌──────────┐   ┌─────────┐  │
│   │ 打卡管理  │   │ 快捷打卡  │   │  设置   │  │

│        ▼              ▼              ▼        │
│  打卡操作页     打卡操作页(⋮菜单)    数据导出页  │
│  （第二层：隐藏底部导航栏，左上角返回）          │
└─────────────────────────────────────────────┘
```

- **打卡管理**（左）：卡片列表，显示图标、名称、方式标签、🔥 连续天数、🛡️ 数量、⭐ / 📌 标记；点击卡片进入打卡操作页，长按弹出管理菜单。
- **快捷打卡**（中，默认首页）：当前快捷项的今日状态 + 连续天数 + 月历 + 图例 + 记录栏 + 打卡按钮；随心记项改为「写一条」悬浮按钮 + 周末视图。
- **设置**（右）：数据导入、数据导出、联网增强、外观主题、关于；版本号连点 5 次可开关管理员模式。
- **打卡操作页**（第二层）：与快捷页同一套日历 / 记录栏 / 打卡按钮，但不会改动快捷配置；右上角 ⋮ 进入详情，详情页可编辑或删除打卡项。

### 日历与记录栏

- 日历圆圈颜色：已打卡（绿）、缺卡 / 破戒（红）、补签（蓝）、部分完成（黄）、无需打卡（橙）、心情日记按心情色；今天 / 选中日以主题色描边。
- 日期下方小标记显示当天次数（×n）与自动打卡（⚡）。
- 记录栏按记录逐条展示：状态、时间、文字、图片宫格（点开全屏）、语音（播放 / 暂停 / 可拖动进度条）、位置、心情 emoji、计时信息。
- 普通打卡文字超过 120 字折叠 5 行并提供「…展开」；日记全文展示、不折叠。
- 点击过去日期可查看当天详情；缺卡日可直接消耗 🛡️ 补签。

### 图片与语音

- 拍照支持多图（最多 9 张），三列宫格预览，可逐张删除或继续添加。
- 语音统一 AAC 16kHz 单声道；语音打卡可设最长时长；随心记语音无时长上限、可在同一块内追加多条。

### 管理员模式（隐藏入口）

- 设置页底部版本号连点 5 次开启，退出 App 自动关闭，不影响原本的修改策略。
- 开启后可修改任意打卡项（含锁定项）与任意记录：状态、打卡时间、归属日期、文字、心情、自动标记、图片、语音、位置；可删除记录、补录任意条记录、清空某日记录、手动增减 🛡️。
- 随心记记录可在管理员模式下重新编辑块流内容（文字 / 图片 / 语音 / 位置），保存覆盖原记录。
- 补录打卡组子项后会自动重新判定组是否完成。

## 数据存储、导出与导入

### Room 表

| 表 | 说明 |
|---|---|
| `checkin_item` | 打卡项（名称、类型、configJson、图标、主题、置顶、暂停、修改策略） |
| `checkin_record` | 打卡记录（归属日期、时间戳、状态、是否自动、素材路径、心情等） |
| `offset_credit` | 抵消机会发放 / 使用记录 |
| `quick_config` | 全局唯一快捷打卡配置 |
| `auto_state` | 自动打卡状态（每日一次去重） |

打卡方式、排期、负打卡、抵消、时间段等规则统一序列化在 `configJson` 中，便于扩展与导入导出。

### 文件存储

- 图片：`{应用内部存储}/files/checkin_photos/{itemId}/*.webp`（最长边 ≤480px，质量 65）
- 语音：`{应用内部存储}/files/checkin_voices/{itemId}/*.aac`（16kHz 单声道）
- 打卡状态不依赖文件：文件丢失时仅显示占位，记录仍有效。

### 导出格式

设置 → 数据导出：勾选打卡项（默认全选，可全选 / 全不选）→ 选择模式 → 导出并分享。

- **仅打卡记录**：`checkin_export_yyyyMMdd_HHmmss.json`，含打卡项、记录、抵消机会、快捷项；素材路径写为 ZIP 内相对路径（`photos/{itemId}/{文件名}`、`voices/{itemId}/{文件名}`）。
- **记录 + 素材**：`checkin_export_yyyyMMdd_HHmmss.zip`，内含 `data.json` + `photos/` + `voices/`；素材缺失时跳过并统计，不中断导出。
- 未勾选的打卡项及其记录、抵消机会不会进入导出文件；快捷项不在选中集时导出为空。

### 导入格式

设置 → 数据导入：选择本应用导出的 JSON 或 ZIP，先预览包含的打卡项 / 记录 / 抵消机会数量，确认后导入；导入前自动备份当前数据到应用缓存目录。

- **打卡项匹配**：优先（创建时间 + 名称），其次名称唯一时按名称，再次创建时间唯一时按创建时间；都无法匹配则新建。已匹配项在导入文件更新时间更晚时覆盖名称 / 类型 / 规则 / 主题等配置，不改变快捷、置顶、暂停与排序状态。
- **记录合并**：按（日期 + 打卡时间戳）去重，已有记录跳过，新记录写入。
- **抵消机会**：已使用的不导入；未使用的按（模式 + 获得日期）去重。
- **快捷打卡项**：仅在本机没有快捷项时设置，已有快捷保持本机设置。
- **素材恢复**：ZIP 导入按相对路径恢复到应用内部目录（目标已存在则复用）；纯 JSON 不恢复素材；缺失素材只统计提示。
- **幂等**：同一文件重复导入结果一致，不会产生重复打卡项或记录。

## 测试与验证

功能验证覆盖以下场景（涉及真实传感器与定位的行为以真机实测为准）：

- **主流程**：三页导航、类型选择四入口、创建 / 编辑回显、锁定策略、详情与返回。
- **打卡方式**：普通、拍照多图、文字、位置（实时定位与范围判定）、时间（倒计时自动完成 / 正计时 / 暂停续时 / 强制模式）、扫码、NFC、语音、自动打卡。
- **规则**：每日次数与「全部完成」、组合打卡完成数、负打卡状态反转、抵消发放与盾牌豁免、补签、排期（每天 / 每周 / 双休 / 大小周）、固定时间段、时间分割归属日、暂停与快捷递补、暂停项沉底。
- **打卡组与习惯打卡**：子项完成判定、组自动成功、部分完成状态、目标天数与超额。
- **日记**：随心记四种块、三列图片宫格、语音进度条、位置末尾、周视图 / 月视图切换、块流编辑；心情日记五档心情、日历颜色、折线图开关。
- **数据**：部分 / 全量导出、JSON / ZIP 结构、素材缺失跳过、导入匹配合并、记录去重、盾牌去重、幂等导入、损坏文件与路径穿越防护、导入前备份。
- **管理员模式**：锁定项修改、记录全字段编辑、多次打卡补录、盾牌增减、日记块流重新编辑。
- **其他**：全局主题换肤、图标切换、NFC 绑定与匹配、联网增强失败降级经纬度、升级安装后数据正常。

> 模拟器无法覆盖真实 GPS 精度、真实计步传感器、NFC 标签与高德地名返回，这些需在真机上验证。
