# 打卡 · Checkin

一款**默认纯本地运行**的多类型打卡 Android 应用，强调自制力工具属性。所有数据默认存储在设备本地，不上传、不同步；**可选联网增强**（设置页开关，用户自行填入高德 API Key 后才发起逆地理编码请求，默认关闭）。支持多种打卡方式自由组合、负打卡（状态反转）规则、连续打卡抵消机制、多日期排期、**块流式随心记日记**与心情日记模式、时间打卡（倒计时 / 正计时 / 暂停续时 / 强制模式），并可将全部或部分数据（可选素材）导出为 JSON / ZIP 供 PC 端解析，支持从本应用导出的 JSON / ZIP 一键恢复。

> 最低系统：Android 7.0+（API 24） · 目标 API 34 · 语言：Kotlin

## 功能特性

### 基础能力

- **默认纯本地运行**：默认无网络请求、无云端同步、无后台常驻 Service，数据 100% 留在设备上。
- **多类型打卡**：普通、拍照、文字、位置、步数、时间、扫码、NFC、语音、自动共 10 种方式，可自由组合。
- **自由组合打卡**：每种方式是独立开关，多选后打卡时逐项完成，全部完成当天变绿。
- **负打卡（状态反转）**：操作 = 破戒失败，无操作 = 默认成功，适合戒手机 / 戒零食等反向自制场景。
- **连续打卡抵消机制**：累积型（A）/ 阈值型（B）/ 周期型（C）三种模式，自动发放 🛡️ 抵消机会补漏签。
- **快捷打卡**：首页专注一个打卡项，长按卡片即可切换；任何时刻唯一（或无），以 ⭐ 标识。
- **打卡日历**：月历视图展示每天状态；点击过去日期查看当天详情（时间、文字、图片、语音）。
- **修改策略**：创建时可选「不可修改」或「N 天可改一次」，锁定规则防作弊。
- **主题系统**：8 套花卉植物风格主题，仅保留打卡按钮色与今天描边色。
- **数据导出**：可勾选部分或全部打卡项；两种模式可选——仅打卡记录（JSON）或记录 + 素材（ZIP，照片 / 语音一并打包）。
- **数据导入**：从本应用导出的 JSON / ZIP 一键恢复；按创建时间匹配合并（名称作后备），记录自动去重合并，素材一并恢复，导入前自动备份。
- **状态与文件独立**：打卡状态写入数据库即最终状态，图片 / 语音文件丢失不影响记录。

### 多日期排期

- 创建时可选「每天 / 每周固定几天 / 双休 / 大小周」。
- 无需打卡日以橙色标注、提示「今日无需打卡」，自动视为完成、不中断连续。
- 大小周：大周 = 单休（周六需打卡），小周 = 双休，创建时选本周开头按周交替。

### 组合打卡增强

- **组合完成数**：多选时可设「完成任意 N 项即完成」（0 = 全部），部分完成当天显示 🟡。
- **环形调节**：完成数 1~总数−1 显示数字，总数显示「全部」，+ / − 双向循环不卡边界。
- **已完成项持久化**：组合打卡时已完成的方式当天显示 ✅ 且不可重复打卡（退出重进仍保留）。
- **按钮文案递进**：首次「打卡」→ 后续「继续打卡 (n/总数)」。

### 固定时间段打卡

- 设定时间窗口（如 5:00–8:30），仅窗口内可打卡成功，适合早起场景。
- 与负打卡互斥（圆形单选），不支持跨天窗口，开启后不可选自动打卡。
- 窗口外按钮禁用并提示；**超过结束时间未打卡当天直接红色缺卡**（无需等次日）。

### 无限次数与排序

- **无限次数**：每日次数设为「不限」，打一次立即完成当天状态，按钮显示「继续打卡（N）」，日期下累计 n 次。
- **拖拽排序**：打卡管理页长按卡片右侧 ⋮⋮ 手柄上下拖动；置顶项不可拖，取消置顶回未置顶区最上方。

### 时间打卡

- 原名倒计时打卡，现支持两种模式：
  - **倒计时**：从设定时长倒数，时间到才能完成。
  - **正计时**：从 0 开始，超过设定时长后才能完成；达标后不操作时间继续走，最终按实际用时记录。
- **暂停保存 / 恢复**（仅正计时）：任意时段暂停写入进度，下次打卡或杀后台重进可继续；暂停当天显示 🟡，备注展示已走 / 剩余。
- **强制模式**（类似番茄钟）：计时期间离开本页（屏幕仍亮）本次计时自动作废（等同放弃，不写记录），需重新开始；**熄屏不算**，解锁回来继续计时；开启后与暂停保存互斥（自动隐藏暂停选项）。
- 负打卡开启时只保留倒计时（隐藏正计时与暂停选项）。

### 随心记（块流日记）

> v1.4.0 起随心记完全重做：不再让用户勾选记录方式，**文字 / 图片 / 语音 / 位置四种块全部内置**，在编辑页自由穿插。

- **新建**：日记打卡 → 选「📔 随心记」即建，无需再选记录方式开关。
- **块流编辑**：点悬浮「✏ 写一条」进入编辑页，底部三个按钮即点即插（文字 / 图片 / 语音），新块追加到末尾；文字块以「再次聚焦到新文字输入框」为分界分段，点回旧文字块可直接续改，和编辑器里点哪改哪一致。
- **图片**：3 列宫格（朋友圈式比例适配，不同屏幕宽度自动适配），单块内可继续追加；长按或点块内 ➕ 追加，可删除。
- **语音**：先弹「开始录音」确认框，点开始后实时显示已录秒数，**无时长上限**；每条语音下方有 ➕ 可在同一块内再录一条；播放带可拖动进度条。
- **位置**：固定在内容流最底部（类似朋友圈定位在最后），点击获取一次位置即附在末尾，不做多块。
- **详情页日记本风**：米色纸张背景（#FAF7F2）、白色卡片、棕色系文字，与全局主题相互独立（预留后续专属日记主题接口）；日历部分默认为紧凑**周视图**，标题显示本周日期范围（如「10月19日 – 25日」），左右箭头切周；点下方折线 ⌄ 展开为矮月历（点 ⌃ 收起回当前周）；下方悬浮「✏ 写一条」白色胶囊按钮进入编辑。
- **记录语义**：只记成功、不记缺卡、不设排期；有记录即绿色，记录天数「有记录 +1、断签不清零」。
- **心情日记**未改动：5 档心情必选，日历取最后一次心情色，备注栏可画折线图。

### 位置联网增强

- 设置页「联网增强」总开关（默认关）→「定位增强」→ 高德 API Key 输入框三级联动。
- 开启后打卡时把经纬度逆地理编码为地名随记录快照保存，显示「📍 地名 + 距离」。
- 不内置任何 Key；关闭增强或请求失败时回退显示经纬度，历史记录不受影响。

### 交互与视觉

- **文字备注**：备注栏无「文字：」前缀，时间后直接衔接文字；普通打卡 >120 字折叠 5 行 +「…展开」。
- **相机取消直接返回**：拍照取消或启动失败直接返回，不降级相册（保证实时性）。
- **今天外边框**：今天无论是否打卡都显示主题色外边框，有填充时结构为「外框 | 白线 | 内部颜色」。
- **图例两行**：第一行日历圆圈颜色（○今日 / ●已打卡 / ●缺卡 / ●补签 / ●部分完成 / ●无需打卡），第二行备注栏图示。
- **录音按钮配色**：统一青色 #39C5BB + 白字。
- **连续天数颜色**：🔥 连续 N 天用深灰 #4A4A4A（红色易与缺卡撞色）。
- **App 图标**：启动器图标与快捷页空状态占位图为初音未来 Q 版形象。
- **创建页卡片式布局**：名称 / 主题 / 打卡方式 / 频率与规则等各自独立白卡，卡片间透出页面底色；打卡类型由选择页确定，创建页不再展示顶部类型切换。日记打卡创建页保留「记录类型」单选（随心记 / 心情日记），编辑已有日记项时锁定。

## 打卡方式

### 普通打卡方式

| 方式 | 说明 | 备注 |
|---|---|---|
| ✅ 普通打卡 | 点一下即完成 | |
| 📷 拍照打卡 | 拍照或从相册选图，自动压缩为 WebP 存储 | 相机取消直接返回，不降级相册 |
| 📝 文字打卡 | 输入文字完成 | 可设最低字数、「不可与上次重复」；备注栏直接衔接文字 |
| 📍 位置打卡 | GPS 定位判定是否在设定范围内 | 支持负打卡（离开设定点才算成功） |
| 👟 步数打卡 | 读取系统计步传感器 | 需身体传感器权限；当前为「开发中」占位 |
| ⏳ 时间打卡 | 倒计时或正计时，达标后可完成；正计时支持暂停续时 | 倒计时：时间到才可完成；正计时：超过目标后可完成，记录实际用时 |
| 🔳 扫码打卡 | 扫创建时生成的二维码，或扫码绑定现有二维码 | 需相机权限 |
| 📡 NFC 打卡 | 碰一碰 NFC 标签，比对标签 ID 后自动完成 | 创建时未绑定标签禁止保存 |
| 🎤 语音打卡 | 录制语音完成，AAC 压缩存储 | 可设最大录制时长；录音按钮 #39C5BB |
| ⚡ 自动打卡 | APP 前台触发自动完成当天打卡 | 每日次数固定为 1；与负打卡 / 固定时间段互斥 |

### 日记打卡方式（日记 tab）

| 方式 | 说明 | 备注 |
|---|---|---|
| 📔 随心记 | 块流日记：文字 / 图片 / 语音 / 位置四种块全部内置，自由穿插，位置固定末尾 | 不选方式开关；日记本风详情页，周/月日历切换 |
| 😊 心情日记 | 5 档心情必选 + 可选文字 | 日历取最后一次心情色；可开关备注栏折线图 |

> 多选任意 ≥2 个不冲突的普通方式即成为**组合打卡**：打卡时按方式卡片逐一完成。可设「完成任意 N 项即完成」（部分完成显示 🟡）。组合打卡每日次数固定为 1。

## 打卡日期排期

创建打卡项时可选择打卡日期排期。**无需打卡的日子**在日历中以**橙色**标注、提示「今日无需打卡」，且**自动视为完成、不中断连续打卡天数**：

| 模式 | 说明 |
|---|---|
| 每天 | 默认排期，每天都需打卡 |
| 每周固定几天 | 周一~周日 7 个圆形多选，仅选中的日子需打卡 |
| 双休 | 周一~周五需打卡，周六、周日休息 |
| 大小周 | 大周 = 单休（周六需打卡），小周 = 双休；创建时选本周开头，之后按周交替 |

## 核心规则

### 负打卡（状态反转）

| 场景 | 显示状态 |
|---|---|
| 某天**执行了**打卡操作 | 该天显示为破戒失败（红色填充） |
| 某天**没有**任何操作 | 该天显示为已打卡（成功） |

负打卡破戒当天连续天数立即归零（不从昨日回溯）。可与所有手动方式叠加，与自动打卡互斥。

### 随心记模式（块流日记）

创建页记录类型选「📔 随心记」（普通 / 日记选择页点「日记打卡」进入）：

| 维度 | 行为 |
|---|---|
| 记录语义 | 只记成功，不记缺卡；当天无操作不产生任何失败标记 |
| 每日次数 | 固定「不限」，不可修改 |
| 排期 | 不设排期（每周固定几天 / 双休 / 大小周全部禁用） |
| 连续天数 | 不计算连续天数，改为**记录天数**：有记录 +1，断签不清零 |
| 内置块类型 | **文字 / 图片（3列宫格）/ 语音 / 位置**，全部内置无需勾选；文字与语音可多段、可穿插，位置固定末尾 |
| 编辑方式 | 悬浮「✏ 写一条」进入块流编辑页；底部按钮即点即追加；点旧文字块直接续改；语音块内 ➕ 追加；图片块内追加/删除 |
| 录音 | 先弹确认框，开始后实时秒数，**无时长上限**；播放带进度条可拖动 |
| 详情页 | 日记本风米色背景、周视图默认（标题显示本周日期范围）、折线展开/收起月历；局内主题独立于全局主题 |
| 其他禁用 | 负打卡、固定时间段、连续抵消机制全部禁用 |
| 按钮文案 | 「✏ 写一条」悬浮按钮；记录后详情页自动刷新当日内容 |

### 心情日记

创建页记录类型选「😊 心情日记」：

| 维度 | 行为 |
|---|---|
| 必选 | 5 档心情之一（😄🙂😐😟😖） |
| 可选 | 附一段文字（不强制） |
| 日历颜色 | 当天最后一次带心情记录的心情色 |
| 折线图 | 当天 ≥2 条带心情且开关开启时，备注栏第一行画趋势线 |
| 计数 | 「n 次 / n 天」只计带心情的记录（附文字不额外计） |
| 备注栏 | 纯心情记录只显示时间 + emoji，不补「完成心情打卡」 |

### 固定时间段打卡

设定当天内时间窗口（如 05:00–08:30），仅窗口内可打卡成功：

- 窗口内：正常打卡。
- 窗口外（未到 / 已过）：按钮禁用并提示。
- 与负打卡互斥（圆形单选）；与自动打卡互斥。
- 不支持跨天窗口；超过结束时间未打卡当天直接红填充。

### 方式互斥矩阵

- 选「普通打卡」→ 其余 8 个手动方式全部置灰。
- 「自动打卡」与普通 / 拍照 / 文字 / 语音 / 时间 / 扫码 / NFC / 位置 / 步数互斥。
- **负打卡 ↔ 自动打卡**互斥（置灰 + 颜文字提示）。
- **固定时间段 ↔ 自动打卡**互斥。
- 自动打卡开启时每日次数固定为 1 并置灰。

互斥开关保持可点击，点击弹出「温馨提示」说明原因。

### 连续打卡抵消机制

| 模式 | 规则 |
|---|---|
| A 累积型 | 每连续 N 天得 1 次，可累积，断签不清零 |
| B 阈值型 | 每连续达 N 天补足到 k 次（不叠加） |
| C 周期型 | 每完成 N 天周期得 k 次，周期中断签从第 1 天重新计 |

补签计入连续天数；补签当天自动视为完成；补签不产生新抵消机会，里程碑周期从补签当天重新起算。

> **负打卡破戒豁免**：点击记录时若持有 🛡️ 可用盾牌，本次破戒**直接抵消为补卡**（显示蓝色圆圈 ↩、消耗 1 盾、**不算破戒次数**）；盾牌耗尽后再点击才真正记为破戒（❌）。历史破戒日**不再自动补签**（自动消耗模式对负打卡失效），只保留手动补签入口；破戒次数、当日详情均只统计 FAIL 记录（补卡不计入次数）。负打卡无操作日视为成功日，不提供补签入口。

### 修改策略

- **LOCKED 不可修改**：创建后规则完全锁定（所有规则控件置灰），仅名称 / 图标 / 主题可改。
- **INTERVAL_N N 天可改一次**：距上次修改不足 N 天时修改入口置灰。
- **FLEX 可随时修改**：日记 tab 创建的项固定为 FLEX。
- **一次性迁移工具**（隐藏入口）：设置页底部**版本号连点 5 次**触发，把历史版本创建的 LOCKED 项一次性迁移为 FLEX（`editPolicy` 改为 FLEX、`lastEditDate`/`editInterval` 清空），仅执行一次，之后入口提示已迁移。迁移项编辑保存后保持 FLEX，不会写回 LOCKED。

### 快捷打卡唯一性

- 任何时刻有且仅有一个（或没有）快捷打卡项。
- 创建第一个打卡项时自动设为快捷；删除后自动切换为排序最靠前的剩余项。
- 切换后首页完全刷新，无残留。

### NFC 打卡

- 创建时开启 NFC → 点「绑定标签」贴近记录 ID；**未绑定禁止保存**。
- 打卡时点 NFC 打卡 → 弹「请贴近标签」→ ID 一致自动完成，不一致提示不匹配。
- 快捷页与打卡操作页均可读卡。

## 数据存储、导出与导入

### Room 表

| 表 | 说明 |
|---|---|
| `checkin_item` | 打卡项（名称、类型、configJson、主题、置顶、修改策略） |
| `quick_checkin_config` | 全局唯一快捷打卡配置 |
| `checkin_record` | 打卡记录（日期、时间戳、状态、是否自动、素材路径、心情值） |
| `offset_credit` | 抵消机会发放 / 使用记录 |
| `auto_checkin_state` | 自动打卡状态 |

### 文件存储

- 图片：`{内部存储}/checkin_photos/{item_id}/{record_id}.webp`（最长边 ≤480px）
- 语音：`{内部存储}/checkin_voices/{item_id}/{record_id}.aac`（16kHz 单声道）
- 打卡状态不依赖文件：文件丢失仅显示占位符，记录保持有效。

### 导出格式

设置 → 数据导出：勾选打卡项（默认全选，可全选 / 全不选）→ 选导出模式 → 导出并分享。

- **仅打卡记录**：`checkin_export_yyyyMMdd_HHmmss.json`（exportVersion 1.2），含打卡项、记录、抵消机会、快捷配置；素材路径统一为 ZIP 相对路径（`photos/{itemId}/{文件名}` / `voices/{itemId}/{文件名}`），不存在的素材仅跳过导入。
- **记录 + 素材**：`checkin_export_yyyyMMdd_HHmmss.zip`，内含 `data.json`（同上）+ `photos/`、`voices/` 目录；素材缺失时跳过并统计提示，不中断导出。
- 未勾选的打卡项及其记录、抵消机会不会进入导出文件；快捷打卡项不在选中集时导出为空。

### 导入格式

设置 → 数据导入：选择本应用导出的 JSON 或 ZIP 文件，预览文件包含的打卡项 / 记录 / 抵消机会数量后确认导入。导入前自动备份当前数据到应用缓存目录。

**匹配与合并口径**

- **打卡项匹配**：优先按（创建时间 + 名称）联合匹配；其次名称唯一时按名称匹配；再次创建时间唯一时按创建时间匹配；均无法可靠匹配的打卡项**新建**。已匹配的打卡项，导入文件更新更晚时以文件内容覆盖名称 / 类型 / 规则 / 主题等配置（不改变快捷、置顶、排序状态）。
- **记录合并**：按（日期 + 打卡时间戳）去重，本机已有的记录跳过，新的记录写入；同一打卡项的记录可跨设备合并而不重复。
- **抵消机会**：已使用的不导入；未使用的按（模式 + 获得日期）去重后写入。
- **快捷打卡项**：导入文件带快捷项时，仅在本机没有快捷项时设置（已有快捷则保留本机设置，不被覆盖）。
- **素材恢复**：ZIP 导入时按相对路径恢复照片 / 语音到应用内部目录（目标已存在则复用）；纯 JSON 导入不恢复素材；素材缺失只统计提示，不中断导入。
- **幂等**：同一文件重复导入结果一致，不会产生重复打卡项或重复记录。

## 测试

项目在 Android 模拟器（emulator-5558）上进行了多轮实测，覆盖多日连续场景：

- **主流程**：三页导航 / 打卡管理 / 快捷打卡 / 设置导出；卡片直达打卡操作页；详情返回。
- **数据导出**：导出页打卡项多选列表加载与默认全选；全不选导出提示、无文件产生；部分勾选 JSON 只含选中项（记录 / 抵消机会同步过滤、快捷项未选中时置空、素材路径相对化、无素材字段保留 null）；全选 ZIP 结构正确（data.json + photos / voices、JSON 引用与包内条目一一对应、快捷项 id 保留）；素材缺失时跳过并统计提示不崩溃；ZIP 部分导出不混入未选中项素材；JSON / ZIP 分享面板均正常触发。
- **数据导入**：全新库导入完整 ZIP（新建 24 项 / 42 记录 / 素材落盘 / 快捷项设置）；同一文件重复导入幂等（0 新建、全部记录去重跳过）；部分勾选 JSON 子集导入只合并命中项；同创建时间多项各自新建不互相污染；同名不同创建时间走名称兜底合并；旧格式（早期导出结构）兼容导入；空 JSON 正常完成；损坏 JSON / 损坏 ZIP / 含路径穿越条目的 ZIP 均给出解析失败提示且不崩溃；取消导入无副作用；导入前自动备份；素材缺失统计不中断。
- **打卡方式**：普通 / 拍照 / 文字 / 位置 / 步数 / 时间（倒计时 + 正计时 + 暂停）/ 扫码 / NFC / 语音 / 自动，各方式采集与完成链路。
- **组合打卡**：多方式组合、完成数 N/M（环形调节循环边界）、已完成项持久化、按钮文案递进。
- **负打卡**：无操作 = 成功、主动记录 = 破戒；破戒当天连续立即归零；多日连续无操作保持绿色。
- **负打卡抵消**：开启抵消后进入页面自动按连续天数发放 🛡️ 机会（连续 3 天 → ×3）；破戒日点击弹「该日破戒…补签？」消耗 1 次机会，补签后显示蓝色圆圈 ↩；无操作日不弹补签；重启不重复发放（幂等）；普通打卡「打卡即发放」路径回归正常。
- **负打卡破戒豁免**：构造「过去 FAIL+同日补签、今天 FAIL、盾牌已被消耗、锚点被重置」的污染场景 → 运行修复逻辑 → 断言同日补签删除、盾牌还回、锚点清空、今日 FAIL 抵消为补卡；再次执行无变化（幂等）；有盾牌时点击记录 → 补卡（蓝色、不算次数）、盾 -1，盾耗尽后再点 → 破戒（FAIL）；负打卡自动消耗模式不再补历史破戒日；普通打卡路径回归正常（SUCCESS + 盾牌发放不受影响）。
- **排期**：每天 / 每周固定几天 / 双休 / 大小周跨周交替；无需打卡日橙色标注且不中断连续。
- **固定时间段**：窗口内可打、窗口外禁用、超结束时间当天直接红填充。
- **时间打卡**：倒计时 / 正计时单选互斥、正计时暂停杀后台续时、达标后继续走、负打卡时只留倒计时。
- **强制模式**：创建页开关与暂停保存互斥；计时中按 Home / 切应用（屏幕亮）本次计时自动作废、不写记录；熄屏解锁后弹窗继续计时。
- **LOCKED 迁移**：版本号连点 5 次迁移 21 个历史 LOCKED 项为 FLEX；迁移后编辑保存保持 FLEX（回归验证）。
- **随心记（v1.4.0 块流重做）**：四种块内置（文字/图片/语音/位置）、底部按钮追加到末尾、位置固定末尾、文字块分段与点击续改、图片3列宫格追加删除、语音块内追加+进度条可拖动、周视图切周后点击正确、折线展开月历立即切换标题、悬浮「✏ 写一条」按钮进编辑、日记本风米色背景与局内主题独立于全局主题。
- **心情日记**：5 档心情、纯心情 / 心情+文字、日历取最后心情色、折线图开关、备注栏不补"完成心情打卡"。
- **创建页 UI**：类型选择页两入口（普通打卡 / 日记打卡）整页背景大按钮；普通打卡创建页无 tab、无记录类型单选；日记打卡创建页内选记录类型（随心记 / 心情日记，切换联动方式区与折线图开关），保存后类型正确落库；新建随心记需至少选一种记录方式；编辑已有普通 / 日记项回显正确（日记项记录类型单选锁定显示）。
- **NFC**：创建绑定 → 快捷页 / 打卡操作页读卡匹配自动完成、不匹配提示。
- **联网增强**：三级开关联动、Key 持久化、失败降级经纬度。
- **连续与抵消**：连续天数累计 / 断签归零 / 补签计入连续 / 里程碑重算。
- **升级兼容**：旧版本数据升级后列表 / 日历 / 记录正常；全新安装空状态引导正常。

> 说明：步数 / 扫码 / NFC / 语音在模拟器上为可交互模拟路径，真实传感器行为需真机验证。联网增强的真实地名返回需真机 + 用户自有 Key 验证，模拟器已验证关闭 / 失败降级路径。
