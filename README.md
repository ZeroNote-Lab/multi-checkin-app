# 打卡 · Checkin

一款**纯本地运行**的多类型打卡 Android 应用，强调自制力工具属性。所有数据存储在设备本地，不上传、不同步、不申请网络权限。支持多种打卡方式自由组合、负打卡（状态反转）规则、双时间分界自定义负打卡、连续打卡抵消机制，并可将全部数据导出为 JSON 供 PC 端解析。

> 目标平台：Android 7.0+（API 24） · 语言：Kotlin

## 功能特性

- **纯本地运行**：无网络权限、无云端同步、无后台常驻 Service，数据 100% 留在设备上。
- **多类型打卡**：普通、拍照、文字、位置、步数、倒计时、扫码、NFC、语音、自动共 10 种打卡方式。
- **自由组合打卡**：每种方式是一个独立布尔开关，可多选组合；打卡时弹出「方式卡片」，逐项完成，全部完成后当天变绿。
- **负打卡（状态反转）**：操作 = 破戒失败，无操作 = 默认成功。适合"戒手机""戒零食""早睡"等反向自制场景，可叠加于任意方式。
- **双时间自定义负打卡**：设定两个时间分界（如 05:00 / 13:00），把一天切成三段，决定每次操作归属哪一天、记成功还是失败。
- **连续打卡抵消机制**：累积型（A）/ 阈值型（B）/ 周期型（C）三种模式，自动发放 🛡️ 抵消机会，可补漏签。
- **快捷打卡**：首页只专注一个打卡项；在打卡管理页长按卡片即可切换，随时更换首页专注对象。
- **打卡日历**：月历视图展示从创建至今每天的状态（成功 / 失败 / 补签 / 自动 / 未来），点击任意过去日期可查看当天打卡详情（时间、文字、图片、语音）。
- **修改策略**：创建时可选「不可修改」或「N 天可改一次」，锁定规则防自己作弊。
- **花卉主题**：8 套花卉植物风格主题（樱花、向日葵、薄荷、薰衣草、珊瑚、海洋、玫瑰、多肉），全局配色统一。
- **数据导出**：一键导出全部打卡项、打卡记录、抵消记录为 JSON 文件，便于 PC 端分析与备份。
- **状态与文件独立**：打卡状态写入数据库即为最终状态，图片/语音文件丢失不影响打卡记录。

## 打卡方式

| 方式 | 说明 | 备注 |
|---|---|---|
| ✅ 普通打卡 | 点一下即完成 | |
| 📷 拍照打卡 | 拍照或从相册选图，自动压缩为 WebP 缩略图存储 | 相机不可用时自动降级相册，图片保存失败不影响打卡状态 |
| 📝 文字打卡 | 输入文字完成 | 可设最低字数、可开启"不可与上次重复" |
| 📍 位置打卡 | GPS 定位判定是否在设定范围内 | 支持负打卡模式（离开设定点才算成功） |
| 👟 步数打卡 | 读取系统计步传感器，达标后确认 | 需身体传感器权限 |
| ⏳ 倒计时打卡 | 倒计时结束后出现「完成打卡」按钮 | 退出界面不中断计时（基于时间戳） |
| 🔳 扫码打卡 | 扫描创建时生成的唯一二维码 | 需相机权限 |
| 📡 NFC 打卡 | 碰一碰 NFC 标签，比对标签 ID | 设备无 NFC 时不可选 |
| 🎤 语音打卡 | 录制语音完成，AAC 压缩存储 | 可设定最大录制时长 |
| ⚡ 自动打卡 | APP 前台触发（冷启动 / 恢复前台 / 跨零点）自动完成 | 触发时展示非阻断式提示，不静默 |

> 多选任意 ≥2 个不冲突的方式即成为**组合打卡**：打卡时按方式卡片逐一完成，各自独立记录。

## 核心规则

### 负打卡（状态反转）

| 场景 | 显示状态 |
|---|---|
| 某天**执行了**打卡操作 | 该天显示为「未打卡」（失败） |
| 某天**没有**任何操作 | 该天显示为「已打卡」（成功） |

克制自己不去打卡 = 打卡成功。负打卡可与所有手动方式叠加。

### 双时间自定义负打卡（三段制）

设两个分界时间 `t1` / `t2`（如 05:00 / 13:00）：

| 操作时段 | 归属日期 | 结果 |
|---|---|---|
| 00:00 – t1（凌晨段） | 昨天 | 记为「未打卡」（FAIL） |
| t1 – t2（中段） | 今天 | 记为「打卡成功」（SUCCESS） |
| t2 – 24:00 | 今天 | 记为「未打卡」（FAIL） |

没有操作的天默认显示「已打卡」（成功）。该模式与「一日多次」互斥，创建时二选一。

### 方式互斥矩阵

- 选了「普通打卡」→ 其余 8 个手动方式开关全部置灰（恒为 0）。
- 「自动打卡」与普通 / 拍照 / 文字 / 语音 / 倒计时 / 扫码 / NFC 互斥（自动触发时无法人工采集素材）。
- 双时间自定义负打卡 ↔ 一日多次互斥。

互斥方式在界面上自动置灰并提示原因。

### 连续打卡抵消机制

创建打卡项时可开启，三选一：

| 模式 | 规则 |
|---|---|
| A 累积型 | 每连续 N 天得 1 次机会，可无限累积，永不过期，断签不清零 |
| B 阈值型 | 每连续达到 N 天补足到 k 次（不叠加），用完后需重新累积 |
| C 周期型 | 每完成一个 N 天周期得 k 次，周期中断签则从第 1 天重新计 |

补签后可手动或自动消耗机会（🛡️×N 显示在卡片上）。

### 修改策略

- **LOCKED 不可修改**：创建后规则完全锁定（编辑页所有规则控件置灰），仅名称/图标/主题/备注可改。
- **INTERVAL_N N 天可改一次**：距上次修改不足 N 天时修改入口置灰。

修改策略本身创建后不可更改。

### 快捷打卡唯一性

- 任何时刻**有且仅有一个**（或没有）快捷打卡项，列表中以 ⭐ 标识。
- 创建第一个打卡项时自动设为快捷打卡；删除快捷打卡项后自动切换为排序最靠前的剩余项；无剩余项时首页显示空状态引导。
- 切换快捷打卡后首页完全刷新（标题、状态栏、日历、记录栏），无残留。

## 界面导航

两层页面体系：

```
┌─────────────────────────────────────────────┐
│               底部导航栏（3 个主页面）           │
│   ┌──────────┐   ┌──────────┐   ┌─────────┐  │
│   │ 打卡管理  │   │ 快捷打卡  │   │  设置   │  │
│   └────┬─────┘   └────┬─────┘   └────┬────┘  │
│        ▼              ▼              ▼        │
│  打卡项详情页    打卡项详情页(⋮)    数据导出页  │
│  （第二层：隐藏底部导航栏，左上角返回）          │
└─────────────────────────────────────────────┘
```

- **打卡管理**（左）：打卡项管理中心。创建 / 编辑 / 置顶 / 暂停 / 删除；长按卡片弹出菜单（设为快捷打卡、置顶、暂停、编辑、删除）；**点击卡片直达快捷打卡页**。
- **快捷打卡**（中，默认首页）：只展示一个打卡项。今日状态栏 + 月历（打卡历史）+ 记录栏（当日打卡明细）+ 唯一打卡按钮；点击日历中过去/今天日期查看详情，不触发打卡。
- **设置**（右）：数据导出（JSON）、数据导入（即将推出）、主题管理（即将推出）、关于。
- 详情页（第二层）：隐藏底部导航栏，左上角返回按钮，标题居中。

## 技术栈

- **语言**：Kotlin 1.9.22（JVM Target 17）
- **UI**：AndroidX 传统 View + Fragment（`BottomNavigationView` 三页导航 + Activity 详情页）
- **数据库**：Room 2.6.1（KSP 编译），库文件 `checkin6.db`
- **构建**：AGP 8.2.2 / Gradle 8.5
- **最低系统**：Android 7.0（API 24）；目标 API 34（Android 14）
- **网络**：无任何网络权限，纯本地
- **后台**：无常驻后台 Service；仅前台注册 `ACTION_TIME_TICK` 广播做跨零点检测，退出前台即注销

## 数据存储与导出

### Room 表

| 表 | 说明 |
|---|---|
| `checkin_item` | 打卡项（名称、类型、configJson、主题、置顶、修改策略、创建时间） |
| `quick_checkin_config` | 全局唯一快捷打卡配置（id 固定为 1） |
| `checkin_record` | 打卡记录（归属日期、时间戳、状态 SUCCESS/FAIL/OFFSET、是否自动、素材路径） |
| `offset_credit` | 抵消机会（模式 A/B/C、发放/使用记录） |
| `auto_checkin_state` | 自动打卡状态（最后自动日期） |

### 文件存储

- 图片：`{内部存储}/checkin_photos/{item_id}/{record_id}.webp`（最长边 ≤480px，质量 60–70%）
- 语音：`{内部存储}/checkin_voices/{item_id}/{record_id}.aac`（16kHz 单声道）
- 打卡状态不依赖文件：文件丢失仅显示占位符，记录保持「已打卡」。

### 导出格式

设置 → 数据导出，生成 `checkin_export_yyyyMMdd_HHmmss.json`，包含 `checkinItems`、`checkinRecords`、`offsetCredits`、`quickCheckinItemId` 等完整数据，JSON 结构便于 PC 端解析与后续导入恢复。

## 测试

项目在虚拟安卓机上进行了多轮实测（含多日期连续使用场景），主要覆盖：

- 三页导航 / 卡片直达快捷打卡页 / 详情页返回
- 方式互斥（普通 ↔ 其他双向置灰）
- 快捷打卡唯一性与切换后数据刷新
- 负打卡、双时间三段归属（凌晨段→昨天失败 / 中段→今天成功 / 晚段→今天失败）
- 多日期连续打卡与断签（跨日、跨月日历自动切月）
- 倒计时「完成打卡」、组合方式卡片、相机降级、文字内容展示
- 修改策略锁定（LOCKED 全控件置灰）
- 导出 JSON 完整性

> 说明：步数 / 扫码 / NFC / 语音在模拟器上为可交互模拟路径，真实传感器行为需真机验证。
